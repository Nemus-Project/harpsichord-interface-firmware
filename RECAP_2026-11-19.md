## How calibration works now (encoder, calibration mode)

Enter calibration mode by holding the encoder button for **2 s** (or holding it
during startup). Holding 2 s again saves and returns to Play mode.

### Gestures

| Gesture | Effect |
|---|---|
| **Turn** | changes what the current encoder mode controls (table below) |
| **Click** | next encoder mode |
| **Double-click** | save everything to FRAM (key thresholds, velocity threshold, detection method); the strip flashes blue |
| **Hold 2 s** | save and return to Play mode |

### Click cycles

- **Position detection:** key select → pluck → release → **detection select** → key select …
- **Velocity detection:** key select → **velocity threshold** → **detection select** → key select …

| Encoder mode | LEDs | Turning does |
|---|---|---|
| Key select | selected key **blue** | choose the key |
| Pluck threshold | selected key **green** | that key's pluck threshold (steps of 10) |
| Release threshold | selected key **purple** | that key's release threshold (steps of 10) |
| Velocity threshold | selected key **orange** | the arm level for **all keys** (steps of 500, 1000–60000) |
| Detection select | **whole strip**: dim green = position, dim orange = velocity | one step switches the method; the next click starts that method's cycle |

### Calibrating velocity detection

1. Open the live plot (Python plotter, `INSTRUCTIONS.md` §6.1) in the
   **velocity view** (key `v`).
2. Click until the whole strip lights up (detection select), turn to **orange**,
   and click.
3. In key select (blue), pick a key to watch.
4. Click → velocity threshold (orange key). Turn to move the **`A`** line:
   presses should dip clearly below it, and the trace at rest should stay well
   above it.
   - Notes trigger on their own → turn **up**.
   - Soft presses don't sound → turn **down**.
5. Double-click to save, or hold 2 s to save and return to Play mode.

The velocity threshold decides *whether* a press is caught, not *when* the note
fires. The timing is set by the peak drop and the velocity window, which are
settings in the code (`haptic_harpsichord.ino`).

### Calibrating position detection

1. In detection select, turn to **green** and click.
2. In key select, choose the key. Click → pluck (green), turn. Click → release
   (purple), turn. Release must stay above pluck.
3. Click → detection select, click → key select for the next key.
4. Or use auto-calibration: send `c` over serial, play every key, then save.

Unsaved changes are lost with the board's reset button.

## Open tasks

**a) Peak drop on the encoder (to decide).** `VELOCITY_PEAK_DROP` (now 0.1) is
still a code setting. It would need a fine scale on the encoder. One option is
for each step to change it by 0.01 (range 0–0.5), which is technically easy.
Whether it's worth it is unclear: lowering it can make Note On at most about one
scan (2 ms) earlier, and the useful range is small (roughly 0.05–0.2). The
velocity window (`VELOCITY_WINDOW` 5 → 4, about 2 ms less lag) may be a more
effective way to make Note On earlier.
